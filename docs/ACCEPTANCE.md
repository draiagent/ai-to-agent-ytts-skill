# 驗收情境

| 輸入情境 | 預期行為 |
| --- | --- |
| 原創 SRT 示例 | 保留所有句子與可靠時間码、使用繁體中文、附正確署名 |
| 中文音訊 | 忠實轉錄，保留語助詞與實際重複 |
| 外語來源 | 逐句翻譯並標記翻譯逐字稿 |
| 沒有來源 | 請使用者提供素材，不產生虛構正文 |
| 網址無法讀取 | 如實回報並要求補充素材，不提供摘要替代 |
| 沒有時間碼的文字 | 不添加臆測時間碼 |
| 聽不清楚 | 標記不確定處，不猜測補齊 |
| 自動字幕 | 註明來源及未核聽狀態 |
| 長篇素材 | 分段處理、檢查交界，不使用「以下略」冒充全文 |

本套件已檢查檔案完整性與匯出內容一致性；上述影音及網路情境需在具備相應工具的執行環境驗收，不代表全部已實測。
