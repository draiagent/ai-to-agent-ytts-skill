# AI to Agent｜YouTube 繁體中文逐字稿技能

**AI Coach 益力康陳董 | 2026 AI to Agent**

將影片內容整理為「一個標題＋繁體中文逐字稿＋固定署名」。不生成摘要、重點整理或心得。

- GitHub 專案名稱：`ai-to-agent-ytts-skill`
- 技能名稱：`ytts-skill`
- 版本：`1.0.0`
- 類型：Agent 指令技能，非獨立影片下載或語音辨識程式。

## 功能

| 項目 | 行為 |
| --- | --- |
| 輸入 | 使用者提供的影片、音訊、字幕或可存取的 YouTube 網址 |
| 標題 | 依實際內容生成一個繁體中文標題 |
| 正文 | 依原始順序忠實轉錄，保留例子、問答與口語重複 |
| 外語 | 逐句翻譯為繁體中文，標示為翻譯逐字稿 |
| 時間碼 | 有可靠資訊才保留，不捏造 |
| 摘要 | 不生成 |
| 署名 | AI Coach 益力康陳董 &#124; 2026 AI to Agent |

## 快速使用

在支援技能的 Agent 環境安裝 `skills/ytts-skill` 後，提供影片或字幕並輸入：

```text
@ytts-skill 將這份影片生成繁體中文逐字稿與標題，不要摘要。
```

若環境使用 `$` 呼叫技能，可輸入：

```text
$ytts-skill 請處理上傳的字幕。
```

亦可提供 YouTube 網址；實際存取與轉錄能力由執行環境提供。只有網址但取不到內容時，技能會請使用者補充影片、音訊或字幕，不憑標題推測內容。
